# AIMonsters

Azure OpenAI のモデル(既定は `gpt-6-luna`)に敵を動かさせる MOD です。**ホストだけ**が入れます(敵の動きも API の呼び出しもホストの PC で行います)。

開発中です。ゲーム内ではまだ試していません。

## 準備
ホストの PC に、次の環境変数を設定してください(設定したあと、Steam とゲームを起動し直します)。

| 環境変数 | 中身 |
|---|---|
| `AZURE_OPENAI_ENDPOINT` | Azure OpenAI のエンドポイント(`https://<リソース名>.openai.azure.com/`) |
| `AZURE_OPENAI_API_KEY` | API キー |

API キーは MOD にも設定ファイルにも書きません。変数の名前は設定で変えられます。

## 敵の AI
- 対象の敵がプレイヤーを見つけ始めると(ゲームの「見えた回数」が 1 回でもたまると)、AI に任せます。
- AI は 2 秒ごとに、狙う相手と動き方(追う・待ち伏せ・回り込み・攻撃・引くなど)を決めます。実際の移動と攻撃はゲームの仕組みで行います。
- 誰も見えない状態が 10 秒続くと、普段の動きに戻ります。API が失敗したときも普段の動きに戻ります。
- AI に送るのは、距離・体力・持っている物などの数字だけです。プレイヤー名は送りません。

## AI が動かす敵
### Loom(ルーム)
- AI が狙う相手を決めます。叩きつけはゲームが自動で行います。
- **貴重品への攻撃**: AI が選んだ貴重品のそばまで歩いて叩きます。衝撃波でそばにいるプレイヤーも巻き込みます。
- 回り込み(相手の背後へ)、離れる、その場で待つ、もできます。
- ルームには「見えた回数」の仕組みがないことがあるため、目から 12m 以内で間に壁がない人を「見えている」とみなします。

### Robe(ローブ)
- 突進(chase)はゲームの突進と同じで、2m まで近づくと自動で攻撃します。
- **待ち伏せ(ambush)**: 相手の背後へ歩いて回り込み、6m まで近づくか、気づかれたとき 10m 以内なら突進します。
- **貴重品への攻撃**: AI が選んだ貴重品のそばまで歩いて攻撃します。
- 回り込み・離れる・待つ、もできます。AI の指示がある間は、見つけた瞬間の突進は AI に任せます。

### Cleanup Crew(クリーンアップクルー)
- AI が狙う相手を決めます。距離の取り方と顔爆弾を投げるのはゲームが自動で行います(顔爆弾は狙う相手を追って飛びます)。
- **貴重品への攻撃**: 顔爆弾は人しか追わないので、その貴重品を持っている人(いなければ一番近い人)を狙います。
- 後ずさり(retreat)、その場で待つ(wait)もできます。待っている間も、投げられるときは投げます。
- MonsterTweaks の「分身と入れ替わる方式」を使っていても、入れ替わった体に AI の指示を引き継ぎます。

### MonsterTweaks との併用
MonsterTweaks が入っていても入っていなくても動きます。AI の指示で動いている間だけ、MonsterTweaks の「行動を変える強化」(ローブの忍び寄りなど)は止まります。
速さや視界などの能力の強化はそのまま効きます。返事待ちや API が使えないときは、MonsterTweaks の強化がふだんどおり動きます。

## 味方の Robe(ローブ)
- **呼び出し方**: ティア 3 の敵を倒したときに出るオーブ(大)を、**つかんだまま割る**と、その場に味方のローブが出ます。レベル中に 1 回だけです(投げて割った・出荷したときは出ません)。
- **見分け方**: 頭の上にヒーラーオーブが浮かんでいます(MOD なしの人にも見えます)。出たときに「Robe: I'm on your side now.」としゃべります。
- **動き**: 呼び出した人についていき、近く(10m)の敵を攻撃しに行きます。プレイヤーは狙いません。
  - 攻撃の当たり判定は各自の PC で動くため、そばにプレイヤーがいるときは攻撃しません。
- 既定では倒されません(プレイヤーの武器の巻き添え対策。設定で変えられます)。倒されてもオーブは落としません。
- 何度も詰まったときなど、ゲームの仕組みで消えた場合は、ついていく人の後ろに出直します(既定 1 秒後。設定「消えたあと出直すまでの秒数」)。
- しゃべるときは、味方のローブに一番近いプレイヤーのセミボットが「Robe:」をつけてしゃべります。

### 味方の Robe と話す
- 味方のローブから 15m 以内のチャットを読んで、AI が返事をします(発言と同じ言語で、短く)。
- 読むのはプレイヤーが自分で打った発言だけです(ほかの MOD がしゃべらせた「Charge start!」やダイスの結果などには反応しません)。
- 直近 10 件の発言(ローブの返事を含む)を覚えているので、会話が続きます。
- 話しかけると、動きも変わります。
  - **ついてくる**: 「ついてきて」(言った人に)、「○○についていって」(名前の一部でも可。ひらがな・カタカナは区別しません)
  - **待つ**: 「ここで待って」(待っている間は敵を攻撃しません)
  - **敵を攻撃**: 「あのクラウンを倒して」(近く 30m の敵)
  - **案内**: 「トラックに帰って」「案内して」で、先に歩いてトラックへ連れていきます。「○○のところへ案内して」なら、その人のところへ。案内される人が遠ければまず迎えに行き、8m 以上離れると止まって待ち、15m 以上離れると迎えに戻ります。その人も目的地まで来たら「着いた。」と言って、その人についていきます(3 分で打ち切り)
  - **攻撃しない**: 「敵を攻撃しないで」で、自分からは敵を攻撃しなくなります。「戦って」「○○を倒して」で元に戻ります
- 名前の照らし合わせはホストの PC で行います(設定「名前を送る」が OFF なら、名前は Azure に送りません。チャットに書いた文はそのまま送られます)。
- **チャットの文は Azure に送られます。** 一緒に遊ぶ人に伝えてください。発言者は既定で P1、P2 などの番号にして、名前は送りません(設定「名前を送る」)。
- 性格は `BepInEx\config\AIMonsters\AllyRobe.txt` で書き換えられます。

## AI への説明を書き換える
`BepInEx\config\AIMonsters\` にテキストファイルを置くと、AI への説明を差し替えられます(ゲームを起動したままでも、次の呼び出しから使います)。
- `Loom.txt` など(敵の英名): その敵の説明(得意・不得意、性格など)
- `Common.txt`: 全体への追加の指示

説明は毎回送るので、長いほど費用が増えます。英語のほうがトークンが少なく済みます。

## 費用の目安
2 秒に 1 回呼ぶので、敵を AI に任せている間は 1 時間に最大で約 1,800 回呼び出します(1 回あたり送信 500〜1,000 トークンほど)。
設定「詳しいログ」を ON にすると、呼び出しごとの使用トークンがログに出ます。

## 設定
`BepInEx\config\shunm.AIMonsters.cfg` で変えられます。
