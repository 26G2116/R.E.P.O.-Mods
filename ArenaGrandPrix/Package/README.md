# ArenaGrandPrix(アリーナ大会)

アリーナレース(Arena Race)とバトルロワイヤル(Disposal Arena)を交互に遊ぶ大会の MOD です。**ホストだけ**が入れれば動きます。

## 遊び方
1. ホストが、レベル・ショップ・トラックのどこかで、チャットに **`/rg`** と打つ → すぐに第 1 戦のレースへ移ります
2. 試合が終わると、順位に応じてポイントがつき、トラックへ移ります
3. トラックのモニターに「その試合の結果」と「総合順位」が出ます(ページは自動で切り替わります)
4. いつもどおりトラックを出発すると、次の試合へ移ります(レース → バトルロワイヤル → レース → …)
5. 決められた数(既定 5 回)の試合のあと、トラックを出発すると**決勝**です
   - ポイントがいちばん多い人(同点なら全員)だけでバトルロワイヤルをします
   - ほかの人は始まってすぐ倒れて、観戦になります
   - 王冠を取った人が優勝です。トラックのモニターに優勝者と最終順位が出ます
6. そのあとトラックを出発すると、ふつうのゲーム(次のレベル)に戻ります

## 順位のつけ方
| 試合 | 1 位 | 2 位から下 |
|---|---|---|
| レース | 最後まで残った人(ゲームの勝者) | 倒れたのが遅い順 |
| バトルロワイヤル | 王冠を取った人 | 倒れたのが遅い順 |

- 0.5 秒以内に続けて倒れた人は同じ順位です(設定で変えられます)。
- 勝者がいない(全員が倒れた)ときは、最後に倒れた人が 1 位です。
- ポイントは、既定では「参加人数 - 順位 + 1」(10 人なら 1 位 10 点、最下位 1 点)。設定の「ポイント表」で好きな点数にできます。
- 試合の途中で部屋を出た人は、その試合の順位に入りません(それまでのポイントは残ります)。

## コマンド(ホストだけ)
| コマンド | 内容 |
|---|---|
| `/rg` | 大会を始める |
| `/rg stop` | 大会をやめる(試合中なら、すぐトラックへ。そのあとの出発はふつうのゲームに戻る) |
| `/rg skip` | 今の試合を、ポイントなしで終わらせてトラックへ(試合の数には数える)。試合が進まなくなったとき用 |

コマンドの言葉は設定で変えられます。

## 設定(`BepInEx\config\shunm.ArenaGrandPrix.cfg`)
| 項目 | 既定 | 内容 |
|---|---|---|
| コマンド | `/rg` | |
| 試合の数 | 5 | 決勝の前の試合の数(1〜20) |
| 最初の試合 | Race | Race = レース、Battle = バトルロワイヤル。そのあとは交互 |
| 決勝 | ON | OFF なら、試合が全部終わったところで大会終了 |
| ポイント表 | (空) | 例「10,8,6,5,4,3,2,1」。空なら「参加人数 - 順位 + 1」 |
| 同着の秒数 | 0.5 | |
| 試合の前に回復 | ON | 試合が始まるときに全員の体力を満タンにする |
| ページを切り替える秒数 | 10 | モニターのページ |
| 文字の大きさ(%) / 行の高さ(%) | 70 / 85 | モニターの文字(枠に収まらなければ自動で小さくする) |

## 注意
- 大会のポイントはホストの PC にだけあります。ホストがゲームを終えたり、メニューに戻ったりすると大会は終わります。
- バトルロワイヤルに入ると、ゲームの仕組みで**チームの買ったアイテムがリセット**されます(ふつうに全滅してアリーナに行ったときと同じ)。アップグレードは残ります。
- 大会の間はショップに寄りません。大会が終わったあとのレベルの番号は、始めたときと同じです。
- REPO_JP さんのアリーナレース用 MOD(ArenaRaceMultiplayerSpawnFix・ArenaRaceCosmeticBoxTrap・ArenaRaceSpeedBoost)と一緒に使えます。前の 2 つは今のゲームでは壊れているので、[ArenaRaceFixes](../../ArenaRaceFixes/Package/README.md) も入れてください。

## 動作確認
- [ ] `/rg` でレースへ移る
- [ ] レースが終わるとトラックへ移り、モニターに結果と総合順位が出る
- [ ] トラックを出発するとバトルロワイヤルへ移る。王冠を取った人が 1 位になる
- [ ] 5 試合のあとの決勝で、決勝に進まなかった人が倒れて観戦になる
- [ ] 決勝のあと、トラックに優勝者が出て、次の出発でふつうのレベルに戻る
- [ ] `/rg stop`・`/rg skip`
