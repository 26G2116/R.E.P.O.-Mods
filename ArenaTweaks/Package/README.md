# ArenaTweaks(アリーナ調整・実験版)

アリーナレース(Arena Race)とバトルロワイヤル(Disposal Arena)を遊びやすく・にぎやかにする、**実験的な** MOD です。**ホストだけ**が入れれば動きます。
[ArenaGrandPrix](../../ArenaGrandPrix/Package/README.md)(アリーナ大会)と一緒に使えます。

## できること
### 1. レースのクラウン
- レースのコースに置かれる貴重品の代わりに、ときどき**クラウン(敵)**を置きます。同時に 1 体までです。
- レースには敵が歩くための道がないので、**置かれた場所から動かずに**、見つけた人をビームで撃ちます。
- 足場のコースが崩れ始めたら隠して、次に貴重品が置かれるときに、その先のコースへ置き直します(同じ 1 体を使い回します)。
- レース中のプレイヤーは、ゲームの仕組みで体力が減りません。ビームでカートが飛ばされたり壊れたりするかは、まだ確かめていません。

### 2. 残機
- 倒れても、決められた回数(既定 2 回)だけ復活します。
- 復活する場所:
  - **バトルロワイヤル**: ステージの中央の床の、少し上(1.5 m)
  - **レース**: トップから順に、カートが床に着いて走っている人を探して、その**少し後ろ(6 m)のコースの床**。新しいカートに乗って復活します
- 倒れると「残り○機。5 秒後に復活！」と読み上げ、最後の 3 秒は「3、2、1」と数えます。復活すると、本人が「復活！残り○機」と言います。
  - 倒れている人の PC では、ゲームの仕組みで読み上げが鳴りません。本人に聞こえるのは、復活したときの「残り○機」だけです
- 復活を待っている人がいる間は、ゲームの「生き残りの人数」の判定を止めます(王冠の檻が開く・レースの勝者が決まる、を復活まで待ちます)。
- 残機がなくなって倒れると、いつもどおり脱落です。
- ArenaGrandPrix の決勝で観戦になった人は、復活しません。

### 3. バトルロワイヤルのアイテム
- 始まりに置かれるアイテムの**数と確率**を、種類ごとに変えられます(既定はゲームと同じ)。
- 床が落ちたあとに**中央に出る武器**の、間隔・出始める段階・種類を変えられます。

## 設定(`BepInEx\config\shunm.ArenaTweaks.cfg`)
### 残機
| 項目 | 既定 | 内容 |
|---|---|---|
| バトルロワイヤルの残機 / レースの残機 | 2 / 2 | 0 で復活しない |
| 復活までの秒数 | 5 | |
| 読み上げる人 | Self | Self = 倒れた本人、Host = ホスト(名前つき)、None = 読み上げない |
| バトルロワイヤルで復活する高さ | 1.5 | 中央の床から何 m 上か |
| レースで復活する位置(後ろ) | 6 | トップの人の何 m 後ろか |
| レースは走っている人の後ろだけ | ON | ジャンプ中の人の後ろには出ない(6 秒見つからなければ、ジャンプ中でもよいことにする) |

### レースのクラウン
| 項目 | 既定 | 内容 |
|---|---|---|
| クラウンを出す | ON | |
| 敵の名前 | Beamer | ほかの敵にもできます(見つからないと、ログに使える名前が出ます)。実験用 |
| 置く確率(%) | 35 | 貴重品 1 つをクラウンに変える確率(小さい貴重品の場所には置かない) |
| 置き始めるコースの番号 | 3 | |
| 置き直すまでの秒数 | 4 | |

### アリーナのアイテム
| 項目 | 既定(ゲームと同じ) |
|---|---|
| 調整する | ON(OFF でゲームのまま) |
| 使うアイテム | 1 個・100% |
| 近接武器 | 5 個・100% |
| 銃 | 3 個・30% |
| カート | 1 個・30% |
| ドローン・オーブ | 3 個・30% |
| 回復 | 3 個・30% |
| 中央に武器を出す間隔(秒) | 5(0 で出さない) |
| 中央に武器を出し始める段階 | 2(最初の床が落ちたあと) |
| 中央に出す種類 | MeleeAndGuns(Melee / Guns / Everything も選べる) |

- 「数」はリストの数より多くできます(同じアイテムが 2 つ目以降も出ます)。
- アイテムの置き場所の数は決まっているので、置き場所が足りないアイテムは出ません(ログに置き場所の数が出ます)。
- バトルロワイヤルは、マルチプレイのときだけアイテムが置かれます(ゲームの仕組み)。

## 実験版の注意
- まだゲームの中で試していません。おかしな動きがあったら、`BepInEx\LogOutput.log` の `[ArenaTweaks]` の行を見せてください。
- 復活は、ゲーム本来の「頭から復活」を使います。先に頭を復活させる場所へ動かし、0.5 秒待ってから復活させます。
- バトルロワイヤルでは、頭が壊れると復活できません。そのため、残機のある人が倒れたときは、頭を壊れないようにします。

## 動作確認
- [ ] レースで、コースの先にクラウンが立っていて、ビームを撃ってくる
- [ ] クラウンの足場が崩れると消えて、先のコースに出てくる
- [ ] レースで倒れると、カウントダウンのあと、トップの人の後ろで新しいカートに乗って復活する
- [ ] バトルロワイヤルで倒れると、中央で復活する
- [ ] 残機がなくなると、いつもどおり脱落する
- [ ] バトルロワイヤルのアイテムの数を変えると、置かれるアイテムが変わる
