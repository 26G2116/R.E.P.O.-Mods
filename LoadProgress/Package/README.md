# LoadProgress

マルチプレイの「読み込みが終わらない」を見える化する MOD です。できることは 3 つあります。

| 機能 | 内容 | 入れる人 |
|---|---|---|
| [ロードの進み具合](#ロードの進み具合) | レベルの切り替わりで、全員のロードの進み具合を 10 段階で表示する | 見たい人(ホストが入れると全員分が詳しく分かる) |
| [途中参加の読み込み](#途中参加の読み込み) | レベルの途中で入ってきた人の読み込みを 7 段階で表示し、止まったら知らせる。マップ受信で止まった人には、ホストがマップの情報を送り直す | 見たい人(送り直しはホスト) |
| [部屋の記録](#部屋の記録) | 入った部屋の様子(ステージ名・チャット・ホストの MOD の通信など)をログに残す | 記録したい人 |

参加者が MOD を入れていなくても動きます(ゲーム本来の通信から進み具合を読み取ります)。

## ロードの進み具合
ロードが始まると画面の左上に自動で表示され、終わると自動で閉じます。

| # | 段階 |
|---|---|
| 1 | 中継シーン到着 |
| 2 | キャラ生成 |
| 3 | マップ生成(ホスト) |
| 4 | マップ受信 |
| 5a | 貴重品受信 |
| 5b | NavMesh 構築 |
| 6 | スポーン |
| 7 | 敵受信 |
| 8 | 生成完了 |
| 9 | 演出終了 |

- **ホストが入れた場合**: 全員の進捗が見えます。MOD なしの人の 5a・5b などは推定で表示します。
- **参加者が入れた場合**: 自分の進捗は全段階が見えます。ほかの人の分は、ゲームが共有している範囲と、ホストやほかの導入者から届いた情報で表示します。

## 途中参加の読み込み
LateJoinNow などの途中参加 MOD で、レベルの途中に入ってきた人の読み込みを 7 段階で表示します。

| # | 段階 | 分かる合図 |
|---|---|---|
| 1 | 参加 | 部屋に入った |
| 2 | キャラ生成 | 参加者のキャラができた |
| 3 | マップ受信 | マップのパーツの受信が終わった |
| 4 | スポーン | スポーンが終わった(ホストだけが受け取る。ほかの人の画面では次の段階で埋まる) |
| 5 | 敵受信 | 敵の受信が終わった(ショップ・トラックでは飛ばす) |
| 6 | 生成完了 | 参加者の画面で生成が終わった(見た目の同期が届いた) |
| 7 | 動き始め | キャラが動いた |

- 1 つの段階で 20 秒止まると橙色、45 秒止まると赤色になります。ログにも「[途中参加] ○○: 「3 マップ受信」で 45 秒止まっています」のように出るので、どこで止まったか分かります。
- 途中で抜けた人は「抜けました(○○の途中)」と出して、ログにも残します。読み込みが終わった人の表示は 5 秒後に消えます。
- 参加者も LoadProgress を入れていれば、その人の報告から「NavMesh 構築中」なども出します(名前の横の * は MOD なしの人)。

### マップの送り直し(ホスト)
途中参加の人が「3 マップ受信」で止まって、読み込みが終わらないことがあります。そのときはホストが、足りないかもしれないマップの情報を送り直します。
- 参加から 8 秒たっても「マップ受信」が終わらなければ、10 秒ごとに最大 3 回送り直します。
- 送るもの:
  - 無効になっているマップのパーツのつながり。途中参加 MOD が送らない分で、最初の 1 回だけ送ります。同じパーツに 2 回送ると壁やドアの向きがずれるので、途中参加 MOD が送ったパーツには送りません。
  - パーツの数。ホストで送れるパーツが目標の数より少なければ、送れる数を伝えます(足りないパーツを待ち続けないように)。
- 送り直すたびに、ホストのパーツの内訳をログに出します(`[途中参加] ○○: マップ受信で止まっているので送り直しました…`)。送り直しても進まないときは、この行を作者に教えてください。

## 部屋の記録
入った部屋の様子を `LogOutput.log` に残します(`[部屋の記録]` で始まる行)。ほかの人の部屋で、ホストがどんな MOD で何をしているかを、あとから調べるための機能です。**自分の PC のログに書くだけで、外には送りません。**

- **ステージが始まるたびに**: ステージ名、ホスト、人数
- **部屋とホストのカスタムプロパティ**(MOD が書き込むことがある): 入ったときと、変わったとき
- **チャット**: ホストの MOD がしゃべらせた分には「送ったのは ○○」と付きます。
- **トラックの画面に出た文字**
- **ステージが終わるたびに**: この PC にない MOD の通信(処理できなかった RPC)の回数と、MOD のイベント番号の回数。ゲーム本体にない RPC の名前には `[MOD]` を付けます。

ほかの人のチャットもログに残るので、ログを人に渡すときは気をつけてください。

## 設定
`BepInEx\config\shunm.LoadProgress.cfg` で変えられます。

| セクション | 項目 | 初期値 | 内容 |
|---|---|---|---|
| General | Enabled | true | MOD 全体の ON / OFF(ゲームの再起動後に反映) |
| Network | ShareProgress | true | 自分の進捗(ホストなら全員の進捗)を、MOD を入れているほかの人に送る |
| Display | PositionX / PositionY | 20 / 20 | 表示の位置(画面左上からのピクセル) |
| Display | Scale | 1 | 表示の大きさ(1080p が基準の倍率) |
| Display | LingerSeconds | 2 | ロードが終わったあと、表示を残す秒数 |
| Debug | LogTransitions | true | 各プレイヤーの段階の進みをログに出す |
| LateJoin | Enabled | true | 途中参加の人の読み込みを表示する |
| LateJoin | WarnSeconds / StuckSeconds | 20 / 45 | 1 つの段階でこの秒数止まったら、橙色 / 赤色にしてログに出す |
| LateJoin | HideSeconds | 5 | 読み込みが終わった(または抜けた)あと、表示を残す秒数 |
| LateJoin | MapResend | true | (ホスト)マップ受信で止まった人に、マップの情報を送り直す |
| LateJoin | MapResendSeconds | 8 | (ホスト)参加からこの秒数たっても終わらなければ送り直す |
| Observe | Enabled | true | 部屋の記録をログに残す(ゲームの再起動後に反映) |

## 動作確認
- ロードの進み具合と途中参加の表示は、ゲーム内で動くことを確かめています。
- マップの送り直し(0.3.0)と部屋の記録(0.4.0)は、まだゲーム内で確かめていません。
