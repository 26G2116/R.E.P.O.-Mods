# LoadProgress

マルチプレイのロード中に、全員のロードの進み具合を 10 段階で表示する。
ロードが始まると自動で表示され、終わると自動で閉じる。

| # | 段階 |
|---|---|
| 1 | 中継シーン到着 |
| 2 | キャラ生成 |
| 3 | マップ生成(ホスト) |
| 4 | マップ受信 |
| 5a | 貴重品受信 |
| 5b | NavMesh 構築 |
| 6 | スポーン |
| 7 | 敵受信 |
| 8 | 生成完了 |
| 9 | 演出終了 |

- ホストが導入: 全員の進捗が見える(MOD なしの人は 5a/5b などを推定で表示)
- 参加者が導入: 自分の進捗は全段階、他人はゲームが共有している範囲 + ホストや他の導入者から届いた情報を表示

## 途中参加の読み込み(0.2.0)
レベルの途中で入ってきた人(LateJoinNow などの途中参加 MOD)の読み込みの進み具合を、7 段階で表示する。
**参加者が MOD を入れていなくても分かる**(参加者の PC がゲーム本来の仕組みで送ってくる合図を拾う)。

| # | 段階 | 分かる合図 |
|---|---|---|
| 1 | 参加 | 部屋に入った |
| 2 | キャラ生成 | 参加者のキャラができた |
| 3 | マップ受信 | マップのパーツの受信完了 |
| 4 | スポーン | スポーン完了(ホストだけが受け取る。ほかの人は次の段階で埋まる) |
| 5 | 敵受信 | 敵の受信完了(ショップ・トラックでは飛ばす) |
| 6 | 生成完了 | 参加者の画面で生成が終わった(見た目の同期が届いた) |
| 7 | 動き始め | キャラが動いた |

- 1 つの段階で 20 秒止まると橙色、45 秒で赤色になり、ログに「[途中参加] ○○: 「3 マップ受信」で 45 秒止まっています」のように出る(読み込みが終わらないときに、どこで止まったか分かる)
- 抜けたら「抜けました(○○の途中)」と出してログにも残す。終わったら 5 秒後に消える
- 参加者も LoadProgress を入れていれば、その人の報告から「NavMesh 構築中」なども出す(名前の横の * は MOD なし)
- 設定は `[LateJoin]`(Enabled / WarnSeconds / StuckSeconds / HideSeconds)
