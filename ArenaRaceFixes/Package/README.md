# ArenaRaceFixes

2026 年 11 月 5 日のゲームの更新で動かなくなった、REPO_JP さんのアリーナレース用 MOD を直す MOD です。
元の MOD はそのまま入れておき、この MOD を一緒に入れます。**ホストだけ**が入れれば効きます。

| 直す MOD | 更新後の症状 | この MOD で |
|---|---|---|
| ArenaRaceMultiplayerSpawnFix 4.0.2 | 並べ直しが効かない。全員の PC で `RPC method 'SpawnRPC' ... has wrong parameters` のエラーが出る(MOD のログには「Applied」と出るので気づきにくい)。並べ方も更新前のゲーム用で、今はスタートの箱の外になる | スタートの箱の下の**コースの上**に並べ直す |
| ArenaRaceCosmeticBoxTrap 4.0.0 | コスメボックスに触れても爆発しない。`Failure: TryExplodeFromCollider` の警告(MissingMethodException)がログに出続ける | 触れたら爆発する |

- 元の MOD が入っていなければ、その分は何もしません。
- ArenaRaceSpeedBoost 4.0.0 は今のゲームでもそのまま動くので、直していません。

## レースのスタート(ArenaRaceMultiplayerSpawnFix)
今のゲームでは、全員がスタートの箱に入り、合図で床が開いて下のコースへ落ちます。箱は狭いので、大人数(20 人など)は入りきりません。
この MOD は、全員を**箱の下のコースの上**に並べます。

- 先頭の列は箱の真下です。そこから後ろ・前の順に列を足していきます。
- 横に並ぶ人数は、元の MOD の設定「HorizontalPlayers」(既定 10 人)です。元の MOD の「VerticalPlayers」(列の数)は使わず、人数とコースの幅に合わせて列を増やします。
- コースの床の上で、カートの四隅もコースに乗る場所だけ使います。はみ出す場所は飛ばして、その分の列を増やします。
- だれがどこに入るかは、元の MOD と同じく毎回ランダムです。
- カートは各自の足元に出ます。スタートの合図までは、ゲームの仕組みで運転できません。
- スタートのブースト(元の MOD の StartBoost)は、設定のとおり効きます。
- 箱の下にコースが見つからないときは、ゲームの開始位置(箱の中)のままにします。

元の MOD の並べ方は、ゲームの開始位置から 5 m 上・10 m 後ろに格子を作るもので、更新前のゲーム用でした。今のゲームでは箱の外の空中になるため、使いません(設定で選ぶことはできます)。

## 設定(`BepInEx\config\shunm.ArenaRaceFixes.cfg`)
| 項目 | 既定 | 内容 |
|---|---|---|
| 修正: ArenaRaceMultiplayerSpawnFix を直す | ON | OFF にすると、並べ直しを何もしません(変更はゲームの再起動後) |
| 修正: ArenaRaceCosmeticBoxTrap を直す | ON | (変更はゲームの再起動後) |
| レースの開始位置: 並べ方 | Track | Track = 箱の下のコースの上に並べる(おすすめ)、Game = ゲームの開始位置(箱の中)のまま、Spread = 箱の中で重なった人だけ横にずらす、Original = 元の MOD の並べ方 |
| レースの開始位置: 横の間隔 | 1.6 | Track のとき、横に並ぶ人の間隔(m) |
| レースの開始位置: 縦の間隔 | 3 | Track のとき、列と列の間隔(m) |

## ログ
- 起動時に「〜を今のゲームに合わせて直しました」と出れば、修正が効いています。
- レースの始まりに「並べ直し: スタートの箱の下のコース … を先頭に、横 10 人で ○ か所を用意しました(参加 ○ 人)」と出ます。
  「○ 人分の場所がとれませんでした」と出たら、横の間隔を狭くしてください。
- 「〜の版が想定と違うので直しません」と出たら、元の MOD が更新されています。元の MOD だけで動くか確かめて、動くならこの MOD は外してください。
- 起動時の `PlayerAvatar.SpawnRPC method was not found` の警告は元の MOD が出すもので、この MOD を入れれば問題ありません。

## 動作確認
- [ ] アリーナレースで、全員が箱の下のコースの上に並び、カートに乗っている
- [ ] 大人数(10 人以上)でも全員がコースの上に並ぶ
- [ ] スタートの合図まで動けず、合図で走り出せる
- [ ] 「SpawnRPC ... wrong parameters」のエラーが出ない
- [ ] コスメボックスにカートで触れて爆発する(一人で確かめ済み)
